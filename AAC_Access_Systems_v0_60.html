1. User interface / student production mode

Students produce the same target sentence through the selected interface. The app records selections, activations, scan ticks, navigation actions, code elements, prediction selections, corrections, and errors, then compares the run to the maximum-efficiency simulation for that same machine. Timing is intentionally not scored in this unit.
