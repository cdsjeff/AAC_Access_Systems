# AAC Access Systems v0.77

AAC Access Systems is a standalone HTML teaching app for comparing AAC access methods, selection techniques, layout choices, and specialized AAC interface architectures.

## Version focus

v0.77 adds explicit manual spacing controls to the statistical word-prediction and ambiguous 8-key disambiguation interfaces.

## Included files

- `AAC_Access_Systems_v0_77.html` — standalone app file.
- `index.html` — duplicate app file for simple hosting.
- `aac_statistical_prediction_corpus_v0_77.csv` — exported 1,500-string language-model corpus.
- `aac_statistical_prediction_corpus_v0_77.json` — corpus and model metadata.
- `icon_sequencing_dictionary_v0_77.csv` — icon-sequencing dictionary export.
- `CURRENT_UPDATES_AAC_Access_Systems_v0_77.md` — current update notes.

## Running the app

Open `index.html` or `AAC_Access_Systems_v0_77.html` in a modern browser. For classroom distribution, upload the package contents to a web host or GitHub Pages and open `index.html`.
